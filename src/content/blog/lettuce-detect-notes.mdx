## Why reproduce a detector?

Reproduction turns a paper from a static description into a sequence of decisions: data, preprocessing, thresholds, metrics and failure analysis.

## A minimal evaluation frame

For a binary detector, precision and recall can be written as:

$$
\mathrm{Precision} = \frac{TP}{TP + FP}, \qquad
\mathrm{Recall} = \frac{TP}{TP + FN}
$$

```python
def precision(tp: int, fp: int) -> float:
    return tp / (tp + fp) if tp + fp else 0.0
```
